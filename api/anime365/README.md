# Генерация клиента Anime365

`openapi.yaml` — неизменённая локальная копия [официальной спецификации Anime365](https://smotret-anime.org/api/openapi.yaml), доступной также на [smotret-anime.app](https://smotret-anime.app/api/openapi.yaml). Для обновления используется зеркало `.org`. Рабочий домен приложения по-прежнему задаётся настройками Anime365.

Из корня репозитория выполните:

```sh
make generate-anime365-client
```

Цель запускает актуальный `oapi-codegen` через `go run ...@latest`; устанавливать генератор или добавлять его в `go.mod` не нужно. Генерация использует локальную спецификацию и `overlay.yaml`. Сгенерированные клиент и модели находятся в `pkg/anime365client/internal/api/client.gen.go`; вручную этот файл не редактируется. В `pkg/anime365client` остаются операции с сайтом и небольшой фасад над JSON API. Типы ответов JSON API экспортируются через псевдонимы сгенерированных моделей.

Запросы сериала, эпизода и перевода передают `fields` с полями, которые используются при построении сущностей в `internal/show/type.go` и `internal/episode/type.go`. При добавлении чтения новых полей обновляйте соответствующий список в `pkg/anime365client/client.go`. Вложенные `episodes` и `translations` запрашиваются целиком. Для embed параметр `fields` в спецификации не предусмотрен.

## Пробелы официальной спецификации

Схемы не полностью описывают ответы, необходимые sidecar. В `overlay.yaml` добавлены `Series.url`, `Series.genres`, `Series.descriptions`, `Series.episodes`, `Episode.translations` и схема embed (`subtitlesUrl`, `stream[].height`, `stream[].urls`). Неиспользуемое поле `Series.links` исключено из схемы: спецификация описывает его объектом, хотя API возвращает массив. Поля каталога и эпизода сверены с публичными ответами API; схема embed перенесена из прежнего клиента, поскольку успешный запрос требует авторизации и подписки.

Overlay также задаёт стабильные имена четырёх используемых операций, 64-битные идентификаторы и числа с плавающей точкой двойной точности. У `isActive` сохраняется указатель, чтобы отличать отсутствие поля от нулевого значения; отсутствие `data` в успешном ответе считается ошибкой.

Списки пользователя и отметка просмотра в спецификации отсутствуют. Вход, получение профиля, списки и отметка просмотра продолжают работать через сайт и общую cookie-сессию; скачивание субтитров также остаётся обычным HTTP-запросом. Спецификация предлагает отдельный вход через API с зарегистрированным `app` и `access_token`, но этот переход не требуется для кодгена и не меняет существующие настройки авторизации.

Чтобы обновить спецификацию и клиент:

```sh
make update-anime365-openapi
make generate-anime365-client
make fix
go build ./...
```

После обновления проверьте, не появились ли недостающие поля в официальной спецификации, и при необходимости удалите соответствующие дополнения overlay. Сгенерированные файлы исключены из диагностики и автоисправлений правилом `generated: strict`.
