# Генерация клиента Emby

`openapi.json` — локальная копия официальной спецификации OpenAPI 3 из [Emby.SDK](https://github.com/MediaBrowser/Emby.SDK/blob/master/Resources/OpenApi/openapi_v3.json). Версия API указана в поле `info.version`. Генерация использует эту копию и не загружает спецификацию из сети.

Из корня репозитория выполните:

```sh
make generate-emby-client
```

Команда запускает актуальную версию [oapi-codegen](https://github.com/oapi-codegen/oapi-codegen) через `go run ...@latest`. Установка генератора и добавление его в зависимости проекта не требуются. Go загружает генератор в свой кеш модулей. Сгенерированный код использует отдельную библиотеку `github.com/oapi-codegen/runtime`.

Настройки и список используемых операций находятся в `oapi-codegen.yaml`. Клиент и модели генерируются в `pkg/embyclient/client.gen.go`. В этом пакете хранится только сгенерированный код; приложение использует его типы и методы напрямую. Этот файл хранится в репозитории и не редактируется вручную. В `.golangci.yml` для линтеров и форматтеров задано `exclusions.generated: strict`: файлы со стандартным маркером `Code generated ... DO NOT EDIT.` исключены из проверок и автоисправлений.

Чтобы загрузить свежую официальную спецификацию, выполните:

```sh
make update-emby-openapi
make generate-emby-client
make fix
```

`update-emby-openapi` скачивает спецификацию непосредственно в `api/emby/openapi.json`, заменяя локальную копию. После обновления проверьте изменения спецификации и сгенерированного клиента, затем соберите приложение командой `go build ./...`.
