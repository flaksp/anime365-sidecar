# Абстракция медиасервера

`Server` — интерфейс между прикладными сервисами сайдкара и конкретным медиасервером. Загрузчики, очистка библиотеки, обновление метаданных и синхронизация просмотренных серий используют операции с идентификаторами Anime365. Типы SDK, идентификаторы элементов медиасервера, проверка воспроизведения и построение ссылок остаются внутри реализации.

Сейчас интерфейс реализует `internal/emby.Service`. Функция `module.MediaServer` создаёт адаптер Emby и возвращает его как `mediaserver.Server`. Перед запуском фоновых обработчиков `startup.InitializeMediaServer` вызывает `Initialize`: адаптер определяет путь к библиотеке и загружает локальный манифест. Формат манифеста и настройки Emby сохранены.

Для подключения Jellyfin или Plex нужно реализовать `Server` в отдельном пакете и добавить создание и конфигурацию адаптера в `cmd/sidecar/module/mediaserver.go`. Прикладные сервисы менять не требуется. Способ хранения состояния — внутренняя деталь адаптера: он может использовать манифест, SQLite, другое хранилище или работать без локального хранилища. Интерфейс `Server` не требует манифеста.

Если элемент не найден в медиасервере, методы поиска и обновления метаданных возвращают общую ошибку `ErrItemNotFound`. Проверять её следует через `errors.Is`. Ошибки внутреннего хранилища относятся к реализации адаптера и не входят в общий контракт. `EpisodeMetadataForNotification` содержит готовую ссылку и данные для уведомления без зависимости от SDK медиасервера.

Методы безопасного удаления возвращают `false, nil`, если удаление отложено из-за воспроизведения или срока хранения. Ошибки запросов к медиасерверу должны прерывать удаление.
